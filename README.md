# 🚀 Dijit – Career & Learning Platform

A modern web platform built using React and Vite that showcases courses, services, job opportunities, and industry insights.

---

## 🧠 About
Dijit is a responsive web application designed to:
- Explore courses
- Discover job opportunities
- Learn about industries and services

---

## ✨ Features
- Hero landing section
- Courses showcase
- Jobs listing
- Industry insights
- Services overview
- Contact section
- Responsive design
- Smooth animations

---

## 🛠 Tech Stack
- React (TypeScript)
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Router DOM
- React Hook Form
- Zod

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/dijit.git
cd dijit
npm install
```

---

## ▶️ Run

```bash
npm run dev
```

Open http://localhost:5173
